# 场景表达临床校准与试点评估方案

本方案是《场景表达功能性沟通评价与迭代依据》的执行附录。它用于验证“沟通目标 + 信息单元 + 独立性”评价是否与治疗师判断一致；不用于直接宣称临床疗效。

## 1. 进入试点前的固定规则

1. 使用已版本化的场景契约；采集期间不得悄悄更改同一版本的关键信息单元或目标条件。
2. 仅纳入录音质量合格、非模拟 ASR、已保留原始录音和转写文本的作答。
3. 每条样本保留任务契约快照、提示等级、开始等待时间、ASR 服务来源与自动信息单元证据。
4. 任何自动结果均标注为“待临床校准的系统证据”；患者报告不得显示诊断性结论。

## 2. 最小校准数据集

首轮至少抽取 60 条有效场景作答，覆盖医院、购物、家庭、问路、预约/药店等至少 5 类情境；每类尽量同时包含独立完成、提示后完成和未完成的样本。每位患者可贡献多条，但分析时须记录患者来源，避免把同一人的重复表现误当作独立样本。

每条样本由两位具有相应资质的治疗师独立标注：

| 标注项 | 允许值 | 标注依据 |
| --- | --- | --- |
| 沟通目标 | 已达成 / 部分达成 / 尚未达成 | 听者是否据此能采取恰当行动 |
| 必需信息单元 | 已表达 / 未表达 / 不确定 | 音频、转写及场景契约 |
| 自动识别错误 | 漏识别 / 误识别 / 无 | 与自动证据逐项比较 |
| 是否需要修复 | 是 / 否 / 未观察 | 是否出现真实澄清或追问回合 |

两位标注者应先只看到场景、录音与任务契约，不看自动结论、另一位标注或患者历史趋势。完成独立标注后，才进入分歧讨论和最终共识记录。

## 3. 校准判定与迭代门槛

每一轮都输出以下结果：

- 沟通目标的双人一致率与加权 Cohen’s kappa；
- 每个信息单元的精确率、召回率和 F1；
- 自动系统与最终共识之间的目标达成一致率；
- 按场景、提示等级、ASR 来源和录音质量分层的错误分布；
- 自动未识别但治疗师判定已表达的同义表达清单。

首轮规则调整只可以加入经双人共识确认的同义表达，或修正明确的契约歧义。不得为了提高总分而删除困难样本。建议门槛为：沟通目标的双人加权 kappa 不低于 0.70；每个高频必需信息单元的 F1 不低于 0.80；若未达到，则继续规则/任务契约迭代并复测。

只有在保留集上仍达到上述门槛，才允许接入语义证据提取模型。该模型必须只返回“命中的信息单元及文字/时间证据、置信度和不确定项”；最终目标等级继续由可追溯规则层计算，并保留治疗师推翻入口。

## 4. 试点评估康复效果

对每位参与者记录基线、训练后和随访三个时间点。训练内效果与泛化效果分开统计：

- **训练内：** 相同或可比难度场景中的独立目标达成率、信息完整度、提示等级和过程指标；用基线 3 次与近期 3–5 次有效作答的中位数比较。
- **泛化：** 未练过的平行场景，在至少两个不同日期完成；只有两日均独立达成沟通目标才报告“可能泛化”。
- **阶段性临床与主观效果：** 由治疗师记录 WAB、CADL，并收集患者/家属对日常沟通变化的报告。系统趋势不得替代这些量表。

阶段报告必须同时列出样本数量、无效录音/失败 ASR 的数量、治疗师复核比例和数据缺失情况。小样本、单场景或未完成随访时，只能报告可行性与观察到的变化，不能报告疗效。

## 5. 数据治理与停止条件

采集前取得对应的知情同意；导出用于标注的数据仅包含最小必要信息，并按项目的数据访问和保留规则处理。若发现自动系统对某类患者、某一场景或某种录音条件持续存在高漏识别/误识别，应暂停该分层的自动结论，仅保留治疗师复核，直至完成再校准。

试点结束后，将“契约版本—标注集版本—规则/模型版本—验证结果”一并归档，以便每个患者报告都能追溯到当时采用的评价方法。
