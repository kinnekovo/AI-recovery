# 言语康复智能体：成熟 Web 产品迭代清单

日期：2026-09-02

## 使用方式

本清单用于配合 `doc/言语康复智能体_产品落地实现路线图.md` 推进真实产品化开发。

执行规则：

- 每次只做一个小改动。
- 每个改动完成后必须验证。
- 验证通过后在本文件打勾。
- 验证未通过则先修当前改动，不进入下一项。
- 数字人视觉短期只采用“上传头像直接作为 Static 2D Avatar”的路线。
- 常规后端算法、训练闭环、前端交互、报告、权限和部署优先于高级数字人。

状态标记：

```text
[ ] 未开始
[~] 进行中
[x] 已完成并验证
[!] 已实现但验证受阻或失败
```
