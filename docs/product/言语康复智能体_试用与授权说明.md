# 言语康复智能体试用与授权说明

本文档用于第一轮小规模试用，适合患者、家属和治疗师阅读。当前系统是言语康复训练辅助工具，不替代医生诊断、治疗师评估或线下康复治疗。

## 1. 本次试用目的

本次试用主要验证：

- 患者能否独立或在少量帮助下完成每日训练。
- 上传头像作为“可靠头像陪练”是否能提升陪伴感。
- 录音、分析反馈和报告是否容易理解。
- 治疗师能否通过训练记录、趋势和阶段报告了解患者训练情况。
- 家属能否通过陪伴观察页理解“是否练了、是否稳定、我能怎么陪”。

第一轮建议范围：

- 3-5 位患者。
- 1-2 位治疗师。
- 每位患者试用 1-2 周。
- 每天训练 5-10 分钟。

## 2. 当前数字人说明

当前数字人采用“可靠头像陪练”方案：

- 患者上传一张头像，系统将头像展示为康复陪练形象。
- 训练开始、任务切换和结果反馈时，头像陪练会播放引导语音。
- 当前不使用 3D 数字人、真人视频数字人或实时口型同步。
- 声音可先使用系统默认声音；如果上传声音样本，必须先确认声音授权。

后续如果升级为声音克隆、口型动画或更拟真的数字人，会重新说明用途并确认授权。

## 3. 患者使用流程

患者登录后按以下顺序使用：

1. 创建或选择康复智能体。
2. 上传头像，确认形象使用授权。
3. 可选上传声音样本，确认声音使用授权。
4. 查看今日训练建议。
5. 进入跟读训练或场景表达训练。
6. 听头像陪练说明，按页面提示录音。
7. 提交录音，等待系统分析。
8. 查看本次训练反馈和下一步建议。
9. 在报告页查看近期练习状态。

患者需要知道：

- 系统反馈只用于训练参考，不代表临床诊断。
- 如果录音太短、太轻或环境太吵，结果可能不稳定。
- 如果听不懂建议，可以请治疗师或家属协助解释。
- 遇到不舒服、疲劳或情绪压力，应停止训练并联系治疗师。

## 4. 家属使用流程

家属登录后按以下顺序使用：

1. 查看是否有待确认的患者绑定。
2. 确认绑定后，进入陪伴观察页。
3. 查看患者最近是否训练、训练是否稳定。
4. 回听允许查看的近期训练录音。
5. 阅读系统或治疗师给出的陪伴建议。
6. 如果不再参与陪伴，可解绑患者。

家属需要知道：

- 家属端不展示治疗师用的完整专业量表。
- 家属只能查看已经确认绑定的患者。
- 解绑后不能继续查看该患者信息。
- 家属端建议用于日常陪伴，不用于自行调整医学治疗方案。

## 5. 治疗师使用流程

治疗师登录后按以下顺序使用：

1. 查看被分配患者列表。
2. 在工作台查看试用质控：完成率、录音缺失、低质量录音、provider 失败。
3. 查看患者训练记录和趋势。
4. 查看或导出阶段报告。
5. 对自动生成的阶段评估进行确认或修正。
6. 必要时通过自然语言备注补充训练建议。
7. 在系统状态页查看数据库、文件存储和 provider 配置状态。

治疗师需要知道：

- 治疗师只能访问分配给自己的患者。
- 系统过程指标是辅助信息，治疗判断仍以治疗师专业判断为准。
- 低质量录音、mock provider 或 fallback 数据不应作为强临床依据。
- 阶段报告可用于复盘和沟通，但正式医疗文书需由机构规范确认。

## 6. 数据采集说明

试用过程中可能采集和保存：

- 账号信息：用户名、角色、创建时间。
- 患者档案：训练状态、当前智能体、能力画像。
- 头像文件：用于 Static 2D Avatar 展示。
- 声音样本：仅在患者主动上传并确认授权后保存。
- 训练录音：用于语音识别、声学分析和训练反馈。
- 训练结果：过程指标、反馈文本、训练记录和报告。
- 治疗师备注：用于补充解释和训练建议。
- 家属绑定关系：用于控制家属可见范围。
- 运行日志：用于定位错误、provider 失败、文件访问问题和系统故障。

系统不会把第三方服务密钥放到前端。文件访问通过后端鉴权接口控制，不直接公开 storage 目录。

## 7. 授权说明

形象授权：

- 上传头像前需要确认形象使用授权。
- 头像用于患者自己的康复智能体展示。
- 已授权头像可能被患者本人、管理员、被分配治疗师和已绑定家属在系统内查看。
- 撤回形象授权后，系统不应继续基于该形象生成新内容。

声音授权：

- 上传声音样本前需要确认声音使用授权。
- 声音样本用于生成或准备生成康复陪练语音。
- 当前阶段可以不用声音样本，直接使用默认系统声音。
- 撤回声音授权后，系统会清除声音克隆标识，不应继续使用该声音生成新语音。

训练录音授权：

- 患者提交训练录音后，系统会用于训练分析和报告生成。
- 训练录音可能被患者本人、管理员、被分配治疗师和已绑定家属在系统内查看或回听。
- 如需删除历史录音或停止参与试用，应联系试用负责人。

## 8. 如何撤回或停止

患者可以：

- 在智能体列表中撤回形象授权。
- 在智能体列表中撤回声音授权。
- 停止继续训练。
- 联系试用负责人停用账号或删除相关数据。

家属可以：

- 在家属端解绑患者。
- 解绑后不再查看该患者训练信息。

治疗师或管理员可以：

- 撤销治疗师-患者分配。
- 停用试用账号。
- 根据试用要求导出、备份或删除数据。

## 9. 风险和限制

- 系统反馈可能受到录音质量、网络、provider 状态和算法限制影响。
- 当前训练建议仍是辅助建议，不是个性化医疗处方。
- 当前数字人是静态头像陪练，不代表真人在线指导。
- 小规模试用阶段可能出现服务中断、分析失败或报告延迟。
- 如果患者出现身体不适、明显疲劳或情绪波动，应立即停止训练。

## 10. 试用前确认清单

患者确认：

- 已了解系统不是医疗诊断工具。
- 已了解会保存训练录音和训练结果。
- 已了解头像和声音授权可以撤回。
- 已了解不适时可以停止训练。

家属确认：

- 已了解只能查看绑定患者的信息。
- 已了解陪伴建议不能替代治疗师意见。
- 已了解解绑后不再查看患者信息。

治疗师确认：

- 已了解系统指标是辅助信息。
- 已了解低质量录音和 mock/fallback 数据需要谨慎解释。
- 已了解患者分配和文件访问权限边界。

试用负责人确认：

- 已创建试用账号。
- 已完成治疗师-患者分配。
- 已完成家属绑定确认。
- 已确认备份策略和问题反馈渠道。
- 已确认 `/api/health` 和系统状态页可用。
