# 言语康复智能体_MVP需求说明（V2）

## 1. MVP目标

MVP版本用于验证核心产品闭环：

> 用户创建个性化陪伴智能体 → 智能体使用用户熟悉的声音进行陪伴 →
> 用户完成言语训练 → 系统给予反馈 → 保存康复过程数据。

核心验证：

1.  个性化智能体是否能够增强训练意愿；
2.  言语训练流程是否自然可用；
3.  语音记录、评分和反馈闭环是否成立。

------------------------------------------------------------------------

# 2. MVP用户范围

第一阶段仅实现患者用户。

角色：

-   patient

暂不实现：

-   family
-   admin
-   therapist

但数据库和架构保留未来扩展能力。

------------------------------------------------------------------------

# 3. MVP核心流程

完整流程：

    注册登录

    ↓

    创建陪伴智能体

    ↓

    上传头像 + 声音样本

    ↓

    声音克隆生成 voice_id

    ↓

    生成欢迎语音

    ↓

    进入训练

    ↓

    完成言语任务

    ↓

    录音上传

    ↓

    评分反馈

    ↓

    保存训练记录

# 4. 个性化智能体模块

## 4.1 创建智能体

用户输入：

-   智能体名称
-   与用户关系
-   陪伴风格

示例：

    名称：妈妈
    关系：母亲
    风格：温柔鼓励

------------------------------------------------------------------------

## 4.2 上传资料

支持：

### 图片

上传：

-   智能体头像

### 声音

上传：

-   10\~30秒声音样本

用于声音复刻。

------------------------------------------------------------------------

## 4.3 声音克隆流程

流程：

    用户声音样本

    ↓

    后端调用声音克隆服务

    ↓

    返回 voice_id

    ↓

    保存到 agents 表

    ↓

    调用 TTS

    ↓

    生成智能体欢迎语音

MVP不训练声音模型，仅调用成熟服务。

------------------------------------------------------------------------

## 4.4 智能体展示

展示：

-   头像
-   名称
-   关系
-   欢迎语音

第一版：

头像 + 个性化声音。

暂不实现：

-   真人级数字人
-   实时视频驱动

------------------------------------------------------------------------

# 5. 言语训练模块

MVP包含两类训练。

## 5.1 跟读训练

目标：

训练：

-   发音清晰度
-   流畅度
-   音量
-   句子完整性

流程：

    展示目标句子

    ↓

    播放示范

    ↓

    用户录音

    ↓

    系统分析

    ↓

    反馈

示例：

    请跟我说：

    今天天气很好。

------------------------------------------------------------------------

## 5.2 场景表达训练

目标：

训练：

-   信息组织能力
-   自主表达能力
-   语言生成能力

流程：

    展示场景图片

    ↓

    智能体提出问题

    ↓

    用户自由表达

    ↓

    系统评价表达内容

示例：

场景：

医院看病。

任务：

"请告诉我图片中发生了什么。"

------------------------------------------------------------------------

# 6. 训练难度设计

采用二维训练体系：

## 内容复杂度

L1-L5

例如：

-   L1：简单词语
-   L2：短句
-   L3：图片描述
-   L4：情景表达
-   L5：开放交流

## 自主程度

S1-S4

例如：

-   S1：完全跟读
-   S2：关键词提示
-   S3：半开放表达
-   S4：自由表达

------------------------------------------------------------------------

# 7. 评价反馈模块

MVP第一版采用模拟评价，但接口设计必须保持真实康复评价兼容。评价逻辑以 `doc/言语康复评价逻辑开发依据.md` 为准，不再以“综合分 + 五维分”作为核心输出。

单次训练输出过程性监控结果：

``` json
{
"process_monitoring":{
"correct_script_word_rate":100,
"error_count":0,
"speech_rate_wpm":190,
"loudness_dba":66
},
"reference_ranges":{
"correct_script_word_rate":"100%",
"error_count":"0",
"speech_rate_wpm":"180-240字/min",
"loudness_dba":"60-78 dBA"
},
"feedback":{
"summary":"本次脚本输出完整，言语速率和响度处于参考范围。",
"suggestion":"继续保持稳定输出，下一次可尝试减少停顿。"
}
}
```

未来替换：

ASR + 声学分析 + 规则评价。LLM 可用于生成自然语言反馈，但不作为量表数据来源。
