# Phase 5.4 过程性解释与录音回放三端更新

## 本阶段目标

在 Phase 5.2/5.3 已完成真实 ASR 与本地声学分析后，本阶段把“系统怎么算出来的”转成三端都能使用的结果展示，并补齐训练录音留存与回放能力。

核心原则：

- 患者端：看得懂本次训练反馈，并能回听自己的录音。
- 家属端：看到绑定患者的近期训练变化和录音，不显示专业量表录入能力。
- 治疗师端：查看每次训练记录、评分、ASR 转写、原始录音和过程性依据，用于复核与临床判断。

## 已完成内容

### 1. 训练录音回放链路

- 训练录音仍在患者训练提交时保存为 `training_audio` 文件资产。
- 训练反馈、患者趋势、家属观察、治疗师训练记录、治疗师评估复核接口都返回对应 `audio_url`。
- 前端新增统一 `AudioPlayback` 组件，通过已登录账号的 API token 拉取录音 Blob 后播放，避免原生 `<audio>` 直接访问受保护接口时缺少鉴权头。

### 2. 后端访问边界

`/api/files/{file_id}/content` 对训练录音新增角色边界：

- 患者：只能访问自己上传并关联到训练记录的录音。
- 家属：只能访问与自己处于 active 绑定关系的患者训练录音。
- 治疗师 / 管理员：可访问已关联训练尝试的训练录音，用于查看训练记录和复核证据。
- 非训练录音文件仍沿用原有 owner 访问规则。

### 3. 患者端展示

- 录音结束后立即显示“本次录音”本地回放，患者可在提交前听到刚录下来的声音。
- 单题反馈页展示本次保存后的录音回放。
- “我的进步”页展示最近训练录音、ASR 转写和患者可理解的简短总结。
- 过程性指标文案继续保持患者友好表达，例如“表达完整度”“需要留意”。

### 4. 家属端展示

- 家属端在可视化陪伴概览中增加“训练录音”模块。
- 每条记录展示训练标题、家属可理解总结、训练时间、训练类型和可回听音频。
- 家属端不出现治疗师复核、指标修正、专业量表录入等能力。

### 5. 治疗师端展示

- 治疗师工作台的每次训练记录增加 ASR 转写和录音回放。
- 自动评估复核页增加“源训练依据”：目标句、ASR 转写、原始录音。
- 自动评估复核页增加“过程性监控依据”：正确生成字数、遗漏/添加/替换、长停顿、插入语、ASR/声学 provider 与局限说明。
- 治疗师仍只负责观察、确认、修正和自然语言补充，不承担患者端训练体验。

## 三端边界确认

| 端 | 能听录音 | 能看评分 | 能看专业过程依据 | 能修改建议/评估 |
| --- | --- | --- | --- | --- |
| 患者端 | 自己本次与历史训练录音 | 简化反馈 | 否，仅显示简化解释 | 否 |
| 家属端 | 绑定患者近期训练录音 | 简化趋势和总结 | 否 | 否 |
| 治疗师端 | 患者训练记录录音 | 完整训练评分和趋势 | 是 | 可用自然语言调整推荐，可复核评估 |

## 后续建议

Phase 5.5 可以继续做“真实服务异常与质量控制”：

- ASR 失败、声学分析失败、录音为空、音频过短时的三端提示差异。
- 治疗师端标记“本次录音质量不足，不纳入趋势”的入口。
- 患者端在录音质量差时给出更温和的重录引导。
