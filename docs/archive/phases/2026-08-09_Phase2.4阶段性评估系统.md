# 2026-08-09 Phase 2.4 阶段性评估系统

## 本次任务

建立训练前后效果评价能力。

目标：

- 新增 `assessment_sessions`。
- 支持训练前、训练中、训练后阶段性评估。
- 支持 WAB、CADL、接受度指标保存。
- 支持阶段性评估历史查询。
- 支持训练前后效果比较。

本阶段不实现 `/evaluation` 前端展示页、折线图或雷达图，这些属于 Phase 2.5。

## 设计方案

新增后端模块：

```text
backend/app/modules/assessment/
├── router.py
├── service.py
├── model.py
└── schema.py
```

设计原则：

- 阶段性评估与单次 attempt 过程性监控分离。
- WAB、CADL、接受度属于量表或问卷数据，不使用 `mock_ai` 自动伪造。
- 当前 MVP 使用 `assessment_sessions.metrics` 的 JSONB 保存量表指标，便于后续增减维度。
- 比较接口默认比较最早一次和最近一次评估，也支持指定 `baseline_id/current_id`。

## 后端接口

新增：

```text
POST /api/assessment
GET  /api/assessment/history
GET  /api/assessment/compare
```

### 创建阶段性评估

请求示例：

```json
{
  "assessment_type": "baseline",
  "evaluation_source": "human",
  "metrics": {
    "wab_information": 6,
    "wab_fluency": 5,
    "wab_grammar": 4,
    "wab_word_order": 4,
    "wab_comprehensibility": 7,
    "wab_repetition_comprehensibility": 6,
    "cadl_score": 68,
    "acceptance_score": 8
  },
  "notes": "训练开始前评估"
}
```

### 查询历史

```text
GET /api/assessment/history
```

可选：

```text
assessment_type=baseline
```

### 比较训练前后效果

```text
GET /api/assessment/compare
```

默认比较最早一次与最近一次。

也可指定：

```text
baseline_id=uuid
current_id=uuid
```

### 5. 接口测试

测试流程：

1. 启动临时 FastAPI 服务。
2. 注册临时 patient。
3. 登录获取 token。
4. 创建 baseline 评估。
5. 创建 after_30_days 评估。
6. 查询 `/api/assessment/history`。
7. 查询 `/api/assessment/compare`。
8. 验证指标差值正确。
9. 验证 `mock_ai` 作为阶段性评估来源会被拒绝。
10. 清理临时账号和评估数据。

预期关键结果：

```text
history_count 2
compare_wab_information_change 2.0
mock_ai_rejected 422
cleanup ok
```

实际测试结果：

```text
history_count 2
baseline_history_count 1
compare_wab_information_change 2.0
compare_by_id_cadl_change 7.0
mock_ai_rejected 422
cleanup ok
```

验证结论：

- `POST /api/assessment` 可以保存 baseline 和 after_30_days 阶段性评估。
- `GET /api/assessment/history` 可以返回历史记录。
- `GET /api/assessment/history?assessment_type=baseline` 可以按评估类型过滤。
- `GET /api/assessment/compare` 默认比较最早与最近一次评估。
- `GET /api/assessment/compare?baseline_id=...&current_id=...` 可以指定比较对象。
- WAB/CADL 指标差值计算正确。
- `evaluation_source=mock_ai` 会被 422 拒绝。
