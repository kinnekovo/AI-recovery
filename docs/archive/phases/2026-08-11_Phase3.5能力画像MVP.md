# 2026-08-11 Phase 3.5 能力画像 MVP

## 本次目标

Phase 3.5 的目标是把 Phase 2 和 Phase 3.4 已产生的数据沉淀成患者“当前能力画像”，为后续自适应训练推荐提供统一输入。

画像数据来源：

- 最近训练后的过程性监控指标。
- 系统自动生成的阶段评估记录。
- 治疗师确认或修正后的复核结果。
- 治疗师复核备注。

本阶段仍然坚持角色边界：

- 患者端只显示简化能力说明和下一步建议。
- 治疗师端可以看到 L/S 等级、指标均值、置信度和证据。
- 后端负责计算画像，前端只展示结果。

### 4. 画像刷新规则

核心服务：

```text
refresh_ability_profile(patient_profile_id)
```

刷新时会读取：

- 最近 10 次完整过程指标。
- 已确认或已修正的阶段评估记录。
- 最近治疗师复核备注。

当前 L/S 初版规则：

- 无足够数据：`L1 / S1`
- 表达完整度 >= 78 且错误 <= 2：`L2 / S2`
- 表达完整度 >= 90 且错误 <= 1：`L3 / S3`
- 表达完整度 >= 92、错误 <= 1 且至少 2 条复核评估：`L4 / S3`

置信度规则：

```text
近期训练数据最多贡献 0.65
治疗师复核数据最多贡献 0.35
```

### 5. 刷新触发点

画像会在以下场景刷新：

- 患者完成训练分析后。
- 治疗师确认或修正自动评估后。
- 治疗师补录阶段评估后。
- 患者或治疗师读取画像时懒刷新。
