# 2026-08-09 Phase 2.3 训练反馈结构更新

## 本次任务

更新训练完成后的反馈结构。

目标：

```json
{
  "process_metrics": {
    "script_accuracy": 95,
    "error_count": 2,
    "speech_rate": 150,
    "loudness": 65
  },
  "feedback": []
}
```

本阶段只实现 Phase 2.3，不实现长期 assessment，不新增 `/evaluation` 趋势页面和图表。

## 设计方案

Phase 2.2 已经在 `attempt_evaluations` 中自动保存 4 个过程性指标。

Phase 2.3 在此基础上改造：

- 后端 `POST /api/attempts/{attempt_id}/analyze` 返回 `process_metrics + feedback[]`。
- 反馈内容按指标生成，每条反馈包含当前表现和建议。
- 后端仍保留旧 `attempt_scores` 写入，避免第一阶段报告模块立刻失效。
- 前端训练结果页改为展示过程性指标和建议，不再展示综合分和五维分。

## 后端改动

更新：

```text
backend/app/modules/scoring/schema.py
backend/app/modules/scoring/service.py
```

新增返回 schema：

- `ProcessMetricsRead`
- `TrainingFeedbackItem`
- `TrainingFeedbackRead`

`analyze_attempt` 现在返回：

```json
{
  "attempt_id": "uuid",
  "process_metrics": {
    "script_accuracy": 95,
    "error_count": 1,
    "speech_rate": 150,
    "loudness": 65
  },
  "feedback": [
    {
      "metric": "speech_rate",
      "current_performance": "言语速率约为 150 字/min，低于参考范围。",
      "suggestion": "建议增加连续表达训练，先用熟悉短句做稳定输出。"
    }
  ],
  "transcript": "这是一次模拟转写结果"
}
```

反馈生成规则：

- `script_accuracy >= 90`：提示脚本完成度较好。
- `error_count <= 1`：提示明显错误较少。
- `speech_rate < 180`：提示语速偏慢，建议连续表达训练。
- `speech_rate > 240`：提示语速偏快，建议放慢。
- `60 <= loudness <= 78`：提示响度处于参考范围。
- `loudness < 60`：提示音量偏低。
- `loudness > 78`：提示音量偏高。
