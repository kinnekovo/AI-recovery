# Phase 4.3 / 4.5 / 4.6 推荐与趋势增强

日期：2026-08-15

## 本批目标

第二批围绕推荐与趋势增强，不改变三端主边界：

1. Phase 4.3 推荐策略配置化。
2. Phase 4.5 趋势归因与提醒。
3. Phase 4.6 自适应推荐增强。

产品边界保持为：

```text
患者端：按推荐完成训练，看到简单原因和提醒。
家属端：看到趋势和陪伴提醒。
治疗师端：查看记录、趋势、归因，必要时用自然语言补充方向。
算法层：负责策略判断、趋势归因、自适应推荐。
```

## Phase 4.3 推荐策略配置化

新增策略模块：

```text
backend/app/modules/training/recommendation_policy.py
```

该模块集中管理：

- 推荐阈值：完整度、错误次数、音量、语速。
- 任务组阶梯：热身、主练、挑战。
- 趋势判断阈值：有效、需调整、波动、观察中。
- 自适应规则：有效时小幅提高，需调整时降低难度，波动时保持。
- 三端提醒文案。

`training/service.py` 不再直接硬编码推荐判断，而是读取策略模块输出。

## Phase 4.5 趋势归因与提醒

推荐效果汇总新增字段：

```text
attribution_points
reminder_level
patient_reminder
family_reminder
therapist_reminder
```

归因逻辑基于：

- 表达完整度变化。
- 错误次数变化。
- 语速是否更接近稳定区间。
- 音量是否更接近自然清楚区间。

三端展示方式：

- 患者端：只显示一句简短提醒。
- 家属端：显示陪伴提醒，不展示专业指标归因。
- 治疗师端：显示趋势归因点和治疗师提醒。

## Phase 4.6 自适应推荐增强

系统推荐现在会读取近期推荐训练效果：

- 趋势有效：小幅提升内容难度和自主程度，建议时长略增。
- 趋势需调整：降低难度，优先回到跟读，减少训练负担。
- 趋势波动：保持当前难度，继续观察。
- 样本不足：保持基础推荐，鼓励继续完成训练。

推荐返回新增：

```text
policy_version
adaptation_note
reminder
```

患者端首页和训练入口会显示自适应说明，但不展示治疗师级归因。

## 旧推荐复核的降级

Phase 3 中保留的推荐复核表和旧接口继续存在，但不再覆盖患者端系统推荐主路径。

当前推荐主路径为：

```text
能力画像 + 近期趋势 -> 策略配置 -> 自适应推荐 -> 患者端任务组
```

治疗师自然语言调整仍通过 `recommendation-note` 进入推荐备注，不作为每次推荐审批。

## 验收点

1. 患者端推荐返回 `source = system`。
2. 推荐返回 `policy_version = phase4.3`。
3. 推荐结果包含自适应说明和患者提醒。
4. 推荐任务组仍是从易到难的 `task_sequence`。
5. 家属端能看到陪伴提醒。
6. 治疗师端能看到趋势归因和提醒。
7. 治疗师端没有新增复杂调参或审批主流程。
