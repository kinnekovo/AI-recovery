## 本地运行方法

### 1. 后端依赖

```powershell
cd backend
python -m pip install -r requirements.txt
```

### 2. 配置数据库

确保本机 PostgreSQL 中存在数据库：

```text
speech_rehab_agent
```

设置环境变量：

```powershell
$env:DATABASE_URL="postgresql+psycopg://postgres:postgres@localhost:5432/speech_rehab_agent"
```

执行迁移：

```powershell
python -m alembic upgrade head
```

### 3. 启动后端

```powershell
conda activate speech-agent
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

接口文档：

```text
http://127.0.0.1:8000/docs
```

### 4. 前端依赖

```powershell
cd frontend
pnpm install
```

如果系统 PATH 中没有 Node，需要先把 Codex 自带 Node 加入当前命令环境，或使用本机 Node.js。

### 5. 启动前端

```powershell
cd frontend
pnpm run dev
```

访问：

```text
http://127.0.0.1:5173
```
