# 2026-08-10 Phase 3.3 角色边界与路由骨架

## 本次任务

建立患者端、家属端、治疗师端的前端路由和布局骨架，避免后续继续把专业评估能力放入患者端。

本阶段只做角色边界和占位工作台，不实现：

- 家属与患者绑定。
- 治疗师真实量表录入表单。
- 治疗师查看患者列表。
- 管理端完整工作台。

## 角色边界

### 患者端

路径：

```text
/home
/agent/list
/agent/create
/training
/evaluation
/report
```

定位：

- 患者训练和查看简化康复记录。
- 不显示 WAB、CADL、baseline、dBA 等专业术语。
- 不录入阶段性量表。

### 家属端

路径：

```text
/family
```

定位：

- 后续查看训练完成情况、趋势稳定性和陪伴建议。
- 当前只提供占位工作台。
- 不录入专业量表，不调整训练方案。

### 治疗师端

路径：

```text
/therapist
/therapist/assessments
```

定位：

- 后续承接 WAB、CADL、接受度等阶段性评估录入。
- 后续查看完整过程性指标和训练前后对比。
- 当前只提供占位工作台和阶段评估入口占位页。

路由守卫规则：

- family 只能访问家属端。
- therapist 只能访问治疗师端。
- admin 暂时允许访问治疗师端骨架，后续管理端建立后再单独拆分。
