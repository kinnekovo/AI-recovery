# R1 V3.1 跟读双轨实施报告

> 实施日期：2026-09-19  
> 范围：跟读 V3 canonical 双轨；不改变 V2、画像、推荐或患者端展示。

## 接入点与双写

唯一接入点是 `scoring.service.analyze_attempt()`：既有 ASR、声学、`rehab-process-v2`、`AttemptEvaluation`、`AttemptAnalysisResult`、`AttemptScore` 和训练完成路径成功提交后，调用 `write_repeat_v3_run()`。V3 写入是 shadow 后处理；失败只在 `AttemptAnalysisResult.raw_model_output.repeat_v3_write` 写入 `retry_required` 记录并产生日志，不回滚患者已完成的 V2 训练。

内部 `rebuild_repeat_v3_run(attempt_id)` 可对单一已有 Attempt 受控重建，供失败重试、固定回归和未来版本升级使用；本轮未批量回填历史记录。

## 六类维度映射

- `content_reproduction`：ASR 对齐率、遗漏/替换/添加与位置、转写和目标快照；明确为内容复现/转写差异。
- `fluency_efficiency`：expression/articulation rate、停顿、有效字符和时长；参考区间仅为 engineering reference。
- `disfluency_events`：重复、插入语、自我修正、长停顿与位置；不合成为临床流利度分。
- `voice_state`：仅保存 `active_loudness_dbfs`，未校准设备仅为相对观察。
- `independence`：提示、求助、启动延迟、完成状态及 E1 engineering heuristic 版本。
- `articulation_evidence`：SOE/精细发音 shadow；disabled/failed 为 `unavailable/null`，不降低其他核心维度的 formal 状态。

没有创建 V3 `overall_score`，也没有继承 `rehab-score-v2` 权重。

## 状态、R0 门控与采用

直接复用 `process_evidence_gate()`：只有 R0 的质量、ASR/provider、`dBFS` 和 `rehab-process-v2` 条件全部满足时产生 `formal` 且 `profile_eligibility=true`。低质量为 `unscorable`；mock、fallback、未知单位或版本为 `review_required`，并保存具体不准入原因。adopted 仅表示该 Attempt 当前 canonical V3 版本，不表示必然可进入未来画像。

`input_fingerprint` 由 V2 持久化分析、声学快照、shadow 标识、任务/目标文本、V3 算法和实际 config snapshot 计算。相同输入复用已有 adopted/candidate run；输入、配置或算法版本变化可新建并采用，旧 run 自动 superseded。

## 固定样本差异与后续

V2 仍返回原有总分和反馈；V3 仅新增专业 canonical 记录，不被旧画像、`phase4.3`、推荐或患者端读取。当前测试样本验证的是结构和门控，不构成临床阈值或疗效结论。

V3.2 的接入点是 `ScenarioDialogueSession` 完整对话完成后的独立映射器，复用 canonical 采用/修订结构，但不得复用跟读的内容对齐、dBFS 或六维定义。
