# 2026-08-10 Phase 3.2 患者端康复记录纠偏

## 本次纠偏

Phase 3.2 原计划把阶段性评估录入放进患者端 `/evaluation` 页面，但实际体验暴露出明显角色边界问题：

- 患者端出现 WAB、CADL、baseline、after_30_days 等专业术语。
- 患者需要面对量表录入表单，认知负担过高。
- 患者端和治疗师端职责混在一起。

本次纠偏将患者端重新定位为：

```text
患者只看得懂的训练进步和下一步练习建议。
```

专业量表录入暂时保留在后端接口，后续迁移到治疗师端或研究人员端。

## 角色边界

### 患者端

负责：

- 开始训练。
- 查看最近是否坚持练习。
- 查看表达是否更完整。
- 查看下一次怎么练。
- 接收鼓励性、低认知负担的反馈。

不展示：

- WAB。
- CADL。
- baseline。
- after_30_days。
- dBA。
- 字/min。
- 阶段性量表录入表单。
- 专业雷达图。

### 家属端

后续负责：

- 查看训练完成情况。
- 查看趋势是否稳定。
- 查看系统给出的陪伴建议。
- 协助提醒患者训练。

不负责：

- 录入专业量表。
- 修改训练方案。

### 治疗师端

后续负责：

- 录入 WAB、CADL、接受度。
- 查看完整过程性指标。
- 查看训练前后效果对比。
- 维护训练建议。
- 后续调整训练方案。

## 前端改动

更新：

```text
frontend/src/views/patient/EvaluationView.vue
frontend/src/views/patient/ReportView.vue
frontend/src/assets/styles.css
```

### `/evaluation` 改动

移除：

- 阶段性评估录入表单。
- WAB/CADL 字段。
- baseline/current 对比表。
- 雷达图。

保留并简化：

- 最近一次训练状态。
- 最近训练变化折线图。
- 下一次练习建议。

患者端展示用语改为：

- `script_accuracy` -> 表达完整度。
- `error_count` -> 需要留意的地方。
- `speech_rate` -> 说话节奏：偏慢 / 合适 / 偏快。
- `loudness` -> 声音状态：偏轻 / 稳定 / 偏响。

### `/report` 改动

移除：

- 过程性监控汇总的专业命名。
- WAB/CADL/接受度明细表。
- baseline 相关文案。

改为：

- 最近练习小结。
- 已完成反馈的训练次数。
- 患者能理解的最近表现。
- 简化阶段记录提示。
- 患者端下一步建议。

## 后端改动

更新：

```text
backend/app/modules/reports/service.py
```

调整 `GET /api/reports/latest` 的建议文案，使其不再出现 baseline 或阶段评估术语。

## 后续规划修正

下一步不应继续在患者端扩展专业评估录入。

推荐顺序改为：

1. 患者端康复记录继续简化和打磨。
2. 明确家属端、治疗师端路由和权限边界。
3. 新增治疗师端阶段评估录入。
4. 后端能力画像只输出给患者端简化建议；完整指标只给治疗师端。
