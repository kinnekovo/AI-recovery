# Phase 4.4 语音评估 Provider 预留

日期：2026-08-16

## 收口原则

真实 ASR、声学分析和 LLM 反馈接入后，评分口径应尽量保持当前 mock 指标字段不变。真实服务只替换数据来源，不改变三端展示和推荐算法依赖的字段。

## 预留环境变量

当前默认全部走 mock：

```env
SPEECH_EVAL_PROVIDER=mock
ASR_PROVIDER=mock
ASR_API_KEY=
ASR_BASE_URL=
ACOUSTIC_PROVIDER=mock
ACOUSTIC_API_KEY=
ACOUSTIC_BASE_URL=
LLM_FEEDBACK_PROVIDER=mock
LLM_FEEDBACK_API_KEY=
LLM_FEEDBACK_BASE_URL=
LLM_FEEDBACK_MODEL=
```

后续接真实服务时，只需要把 provider 名称、key 和 endpoint 写入 `.env`，再在对应 provider factory 中新增真实 provider 实现。

## 保持不变的过程指标

推荐、趋势、家属端和治疗师端继续依赖这四个过程指标：

```text
script_accuracy
error_count
speech_rate
loudness
```

真实服务需要将自己的输出映射到这四个字段：

- `script_accuracy`：目标文本与转写文本的表达完整度，单位 `%`。
- `error_count`：明显错误、长停顿、无意义重复、难以理解发音等事件总数，单位 `次`。
- `speech_rate`：有效表达字数 / 说话时间，单位 `字/min`。
- `loudness`：平均响度，单位 `dBA`。

## 保持不变的评分维度

即时反馈继续使用当前五个评分维度：

```text
overall_score
content_score
clarity_score
fluency_score
loudness_score
prompt_dependence_score
```

真实 LLM 或评分服务需要输出同名字段，避免改动患者端反馈、治疗师端记录和推荐效果趋势。

## 当前实现状态

已完成：

- `Settings` 读取语音评估相关环境变量。
- ASR provider 支持根据 `ASR_PROVIDER` 选择 provider，默认 mock。
- Acoustic provider 支持根据 `ACOUSTIC_PROVIDER` 选择 provider，默认 mock。
- LLM feedback provider 支持根据 `LLM_FEEDBACK_PROVIDER` 选择 provider，默认 mock。
- 若配置为非 mock 但真实 provider 尚未实现，系统安全回退 mock。
- 评分结果的 `raw_model_output` 会记录 requested provider 和实际 provider，便于后续排查。

未接入：

- 真实 ASR 服务。
- 真实声学分析服务。
- 真实 LLM 反馈服务。

## 后续接真实服务的改造点

1. 在对应 provider 文件中新增真实 provider 类。
2. 在 factory 中根据环境变量返回真实 provider。
3. 将真实服务输出映射到现有过程指标和评分维度。
4. 保留 mock fallback，避免外部服务异常时训练闭环中断。
