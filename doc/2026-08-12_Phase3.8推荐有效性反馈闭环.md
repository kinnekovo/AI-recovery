# 2026-08-12 Phase 3.8 推荐有效性反馈闭环

## 本次目标

Phase 3.8 的目标是让系统能回答一个关键问题：

```text
患者是否按推荐开始训练，以及训练后的表现如何？
```

本阶段在 Phase 3.7 的“治疗师复核推荐”基础上继续向后闭环：

```text
能力画像 -> 推荐生成 -> 治疗师复核 -> 患者按建议训练 -> 推荐后表现反馈
```

## 后端改动

### 1. 训练会话保存推荐快照

更新表：

```text
training_sessions
```

新增字段：

```text
recommendation_review_id
recommendation_source
recommendation_snapshot
recommendation_matched
```

说明：

- `recommendation_review_id` 关联治疗师复核建议。
- `recommendation_source` 记录患者当时看到的是系统建议还是治疗师建议。
- `recommendation_snapshot` 保存当时推荐的标题、等级、置信度和备注。
- `recommendation_matched` 记录患者是否按推荐类型开始训练。

这样即使治疗师后续调整推荐，历史训练仍然保留当时的推荐上下文。

### 2. 新增迁移

新增：

```text
backend/migrations/versions/0008_recommendation_session_feedback.py
```

当前数据库版本：

```text
0008_rec_feedback
```

### 3. 训练会话创建支持推荐上下文

更新接口：

```text
POST /api/training/session
```

新增可选 payload：

```text
recommendation_id
recommendation_source
recommendation_headline
```

普通手动训练不传这些字段，因此不会被计入推荐入口训练。

### 4. 治疗师端推荐效果接口

新增：

```text
GET /api/therapist/patients/{patient_user_id}/training-recommendation/effects
```

返回：

```text
total_recommended_sessions
completed_recommended_sessions
matched_sessions
latest[]
```

单条效果包含：

```text
session_id
created_at
training_type
recommendation_source
recommendation_headline
recommendation_matched
status
metrics
summary
```

指标来自推荐训练会话下的过程性评估：

- `script_accuracy`
- `error_count`
- `speech_rate`
- `loudness`

## 前端改动

### 1. 患者端推荐入口带上下文

更新：

```text
frontend/src/views/patient/HomeView.vue
frontend/src/views/patient/TrainingView.vue
```

“按建议开始”现在会进入：

```text
/training/{type}?recommended=1&source=...&recommendation_id=...&headline=...
```

患者手动点击普通训练类型时，不带这些 query。

### 2. 训练会话创建写入推荐快照

更新：

```text
frontend/src/views/patient/TrainingSessionView.vue
frontend/src/api/training.ts
frontend/src/types/api.ts
```

训练页读取 query，并在创建 session 时传给后端。

### 3. 患者训练结果页简化反馈

更新：

```text
frontend/src/views/patient/TrainingResultView.vue
```

如果本次训练来自推荐入口，患者端显示：

```text
已完成建议训练
```

不展示复杂有效性指标，避免患者端专业化。

### 4. 治疗师端推荐后表现

更新：

```text
frontend/src/views/therapist/TherapistProfilesView.vue
frontend/src/api/therapist.ts
```

能力画像页新增“推荐后表现”面板，展示：

- 推荐入口次数。
- 已完成次数。
- 按建议类型训练次数。
- 最近推荐训练摘要。
- 过程指标摘要。
