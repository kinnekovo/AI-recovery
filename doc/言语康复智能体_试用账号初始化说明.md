# 言语康复智能体试用账号初始化说明

本文档用于第一轮 3-5 位患者试用前创建账号和关系数据。

## 1. 默认账号方案

初始化脚本默认创建：

| 角色 | 默认账号 | 用途 |
| --- | --- | --- |
| 管理员 | `trial_admin` | 分配治疗师-患者关系、查看系统状态 |
| 治疗师 | `trial_therapist_01` | 查看被分配患者、复核评估、导出阶段报告 |
| 患者 | `trial_patient_01` 到 `trial_patient_03` | 完成头像陪练训练闭环 |
| 家属 | `trial_family_01` 到 `trial_family_03` | 确认绑定后查看陪伴观察 |

默认密码：

```text
Trial2026!
```

正式试用前建议通过参数设置新的临时密码，并在发给试用人员后提醒首次登录后更换或由管理员重置。

## 2. 预览初始化结果

当前数据库不可用或正式执行前，先 dry-run：

```bash
cd backend
python scripts/init_trial_data.py --dry-run
```

创建 5 位患者和 5 位家属的预览：

```bash
python scripts/init_trial_data.py --dry-run --patient-count 5 --family-count 5 --password "replace-with-temp-password"
```

dry-run 不写数据库，只输出将要创建的账号和关系数量。

## 3. 真实执行

确认 PostgreSQL 可用并已迁移到最新版本：

```bash
cd backend
python scripts/check_database.py
alembic upgrade head
```

执行初始化：

```bash
python scripts/init_trial_data.py --patient-count 5 --family-count 5 --password "replace-with-temp-password"
```

脚本会：

- 创建或更新 `trial_admin`。
- 创建或更新 `trial_therapist_01`。
- 创建或更新指定数量的患者账号。
- 创建或更新指定数量的家属账号。
- 为每个患者创建患者档案。
- 将所有患者 active 分配给 `trial_therapist_01`。
- 将前 N 个家属 pending 绑定到对应患者，家属登录后需要手动确认。
- 调用训练材料 seed，确保患者可进入训练。

脚本可重复执行。已存在账号会更新密码、角色和 active 状态；已存在分配会重新激活；已存在家属绑定会重置为 pending。

## 4. 试用前人工检查

执行后至少检查：

- `trial_admin` 可以登录并访问系统状态页。
- `trial_therapist_01` 可以看到被分配患者。
- `trial_patient_01` 可以创建头像陪练并进入训练。
- `trial_family_01` 登录后能看到待确认绑定，确认后能进入陪伴观察页。
- `/api/health` 数据库和 storage 状态正常。

## 5. 分发账号注意事项

- 不要把账号密码放在公开仓库、群公告或截图里。
- 每位试用人员只拿到自己的账号。
- 患者和家属账号不要混用。
- 如果有人退出试用，应由管理员停用账号、撤销绑定或按试用协议删除数据。
