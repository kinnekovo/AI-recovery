# 2026-08-09 Phase 2.5 康复评估前端展示

## 本次任务

新增患者端 `/evaluation` 页面，展示：

- 当前训练过程性指标。
- 过程性指标折线趋势。
- 训练前 vs 当前的阶段性评估对比。
- WAB、CADL、接受度雷达图。

本阶段不新增数据库表；使用 Phase 2.1 到 Phase 2.4 已完成的数据。

## 设计方案

页面定位为患者端工作台，而不是管理大屏。

设计原则：

- 语言简单，避免诊断式表述。
- 当前指标、趋势图、阶段性对比分区展示。
- 数据不足时给出清楚空态。
- ECharts 只在 `/evaluation` 路由懒加载，避免影响主应用首屏。
