# 2026-08-08 整理言语康复评价逻辑依据

## 本次任务

根据 Word 文档《过程性监控+效果对比.docx》，重新整理言语康复评价逻辑，并将其写入项目 Markdown 文档作为后续开发依据。

同时同步修改现有设计文档中与新评价逻辑不一致的内容。

## Word文档核心内容

Word 文档将评价逻辑分为两部分：

1. 过程性监控
2. 训练前后效果对比

### 过程性监控指标

包括：

- 正确生成的脚本字数百分比
- 错误数
- 言语速率
- 响度

### 训练前后效果对比

包括：

- WAB量表
- CADL量表
- 喜好度与接受度

## 新增文档

新增：

```text
doc/言语康复评价逻辑开发依据.md
```

该文档明确：

- 新评价逻辑取代旧“五维单题评分”框架
- 单次训练应返回过程性监控指标
- 阶段性报告应展示训练前后效果对比
- WAB、CADL、喜好度与接受度属于阶段性量表或问卷数据，不应由模型自动伪造
- LLM 可用于自然语言反馈生成，但不作为量表数据来源
