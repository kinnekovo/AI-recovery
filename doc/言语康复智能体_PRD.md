# 基于个性化陪伴智能体的脑卒中言语康复训练系统

## 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品背景

脑卒中患者在病后恢复过程中，常伴随不同程度的言语障碍，包括：

- 言语表达困难
- 词汇提取困难
- 发音不清
- 语速异常
- 音量不足
- 沟通意愿下降

传统言语康复训练通常依赖康复治疗师或固定训练材料，存在训练成本高、家庭训练缺少指导、长期训练积极性不足等问题。

本项目提出一种基于个性化陪伴智能体的脑卒中言语康复训练系统：

> 利用患者熟悉的人物形象和声音生成陪伴型智能体，将情感化交互融入言语康复训练，通过语音分析和智能反馈帮助患者进行持续训练。

---

# 2. 产品定位

## 2.1 核心定位

面向脑卒中后复合型言语障碍患者的个性化陪伴式言语康复智能系统。

区别于传统康复软件：

传统：
```
患者 → 训练任务 → 评分
```

本系统：
```
患者
 ↓
熟悉的人形象与声音智能体
 ↓
陪伴式训练
 ↓
语音分析
 ↓
个性化反馈
 ↓
持续调整
```

- 任务指导

- 示范

- 反馈


### 陪伴交流模式

用于：

- 自主表达
- 情景交流

负责：

- 提问
- 引导表达
- 维持交流

# 6. 智能体系统

## 6.1 创建流程

```
创建智能体
↓

↓

↓
```

- 配偶

规则：

- 默认绑定一个主要智能体
- 日常训练使用当前智能体

涉及：

- 人脸
- 声音克隆

因此需要：

- 本人授权
- 明确使用范围
- 禁止未经允许传播

# 7. 首次使用流程

```
创建智能体
↓
智能体首次互动
↓
初次能力评估
↓
建立能力画像
↓
生成训练方案
```

## 初次评估

采用渐进式评估：

包括：

- 基础发声
- 词语跟读
- 短句跟读
- 图片命名
- 简单自主表达

形成能力画像：

- 正确生成的脚本字数百分比
- 错误数
- 言语速率
- 响度
- WAB/CADL阶段性变化

# 8. 康复训练系统

## 8.1 引导式言语训练

训练维度：

### 内容难度 L

L1：音节、单词

L2：短语

L3：简单句

L4：复杂句

L5：情景表达


### 自主程度 S

S1：完整模仿

S2：延迟复述

S3：提示表达

S4：自主表达


训练难度：

```
内容难度 L × 自主程度 S
```

---

## 8.2 自主表达训练

形式：

- 图片描述
- 生活主题表达
- 情景交流

例如：

主题：

“去医院看病”

患者根据场景进行表达。

---

# 9. 自适应训练机制

## 9.1 任务内调整

判断患者困难：

- 长时间未开始表达
- 长时间停顿
- 重复失败
- 主动请求帮助

提示等级：

```
无提示
↓
语义提示
↓
关键词提示
↓
句式提示
↓
完整示范
```

## 9.2 长期调整

根据训练历史：

- 提升难度
- 减少提示
- 调整训练比例

# 10. 评价与反馈

评价逻辑以 `doc/言语康复评价逻辑开发依据.md` 为准，采用：

```text
过程性监控
+
训练前后效果对比
```

过程性监控用于单次训练或训练过程中的量化记录，核心指标包括：

- 正确生成的脚本字数百分比
- 错误数
- 言语速率
- 响度

训练前后效果对比用于阶段性评估，核心工具包括：

- WAB量表
- CADL量表
- 喜好度与接受度

## 单题反馈

展示：

- 过程性监控结果
- 与参考范围的比较
- 一个主要建议

例如：

> 本次脚本输出完整，言语速率接近参考范围，可以继续保持稳定输出。

操作：

- 再试一次
- 提示后再试
- 下一题

## 训练总结

展示：

- 过程性监控趋势
- 训练前后效果对比
- 下一步建议

并由智能体进行鼓励反馈。

# 15. 产品创新点

## 创新点1：个性化亲情智能体

利用患者熟悉的人物形象和声音增强训练陪伴感。

## 创新点2：陪伴式康复交互模式

从“完成训练任务”转变为“与熟悉的人共同训练”。

## 创新点3：双维度自适应训练体系

内容难度 × 自主程度。

## 创新点4：语音分析驱动的闭环康复

训练 → 评价 → 反馈 → 调整。
