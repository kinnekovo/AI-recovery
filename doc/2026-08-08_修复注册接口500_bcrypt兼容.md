# 2026-08-08 修复注册接口500：bcrypt兼容问题

## 本次问题

前端注册患者账号时提示：

```text
Request failed with status code 500
```

后端接口已经进入 FastAPI，但注册过程中失败。

## 根因

当前 Conda 环境 `speech-agent` 中安装的是：

```text
bcrypt 5.0.0
passlib 1.7.4
```

这两个版本不兼容。注册接口会调用 `passlib` 对密码进行哈希，`passlib==1.7.4` 在加载 `bcrypt==5.x` 时会失败，导致后端返回 500。

## 本次处理

在 `speech-agent` 环境中安装兼容版本：

```powershell
C:\Users\20651\.conda\envs\speech-agent\python.exe -m pip install bcrypt==4.0.1
```

并重启了后端服务：

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

项目依赖文件已保持固定：

```text
backend/requirements.txt
```

其中包含：

```text
passlib[bcrypt]==1.7.4
bcrypt==4.0.1
```

## 验证结果

使用真实 HTTP 请求测试：

```text
POST /api/auth/register
POST /api/auth/login
```

结果：

```text
register 200
login 200 0 patient
cleanup ok
```

说明：

- 注册接口已恢复
- 登录接口已恢复
- 临时测试账号已清理

## 注意事项

如果以后重新创建 Conda 环境或重新安装依赖，请在 `backend` 目录执行：

```powershell
python -m pip install -r requirements.txt
```

不要只单独安装 `passlib`，否则 pip 可能再次带入不兼容的 `bcrypt 5.x`。

如果后端服务已经启动过，安装依赖后必须重启 uvicorn，否则旧进程仍然使用旧模块。
