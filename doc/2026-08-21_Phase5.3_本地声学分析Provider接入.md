# Phase 5.3 本地声学分析 Provider 接入

## 目标

在不额外接入第三方声学 API 的前提下，将单次训练过程性监控中的声学指标从固定 mock 改成本地音频分析：

- 说话时长 `speaking_duration_seconds`
- 超过 3 秒停顿次数 `long_pause_over_3s_count`
- 估算响度 `loudness_dba`

## 接入方式

新增 provider：

```text
backend/app/integrations/acoustic_analysis/provider.py
```

启用方式：

```env
ACOUSTIC_PROVIDER=local
```

保留 mock fallback：

```env
ACOUSTIC_PROVIDER=mock
```

## 依赖

`requirements.txt` 已新增：

```txt
numpy>=2.0.0
imageio-ffmpeg>=0.5.1
```

本机没有全局 ffmpeg 时，会优先使用 `imageio-ffmpeg` 自带的 ffmpeg。

如需指定系统 ffmpeg：

```env
FFMPEG_BIN=C:\path\to\ffmpeg.exe
```

## 计算口径

### 1. 音频解码

音频统一转为：

```text
16kHz / mono / s16le PCM
```

### 2. 有声片段

按 30ms 切帧，计算每帧 RMS 与 dBFS。

默认有声阈值：

```env
ACOUSTIC_VOICE_THRESHOLD_DBFS=-45
```

### 3. 说话时长

```text
说话时长 = 有声帧数量 * 0.03 秒
```

### 4. 长停顿

在首个有声帧和最后一个有声帧之间，连续静音达到 3 秒，计为一次长停顿。

### 5. 响度

浏览器麦克风无法直接得到真实物理 dBA，因此当前为估算响度：

```text
estimated_loudness_dba = active_rms_dbfs + ACOUSTIC_DBA_CALIBRATION_OFFSET
```

默认校准偏移：

```env
ACOUSTIC_DBA_CALIBRATION_OFFSET=90
```

如后续使用声级计校准，可以调整该 offset。

## 与 Phase 5.2 的关系

Phase 5.2 的过程性监控规则层不需要改结构。启用本地声学分析后：

- `speech_rate_wpm` 会基于真实说话时长变化
- `error_events.long_pause_over_3s` 会基于真实静音段变化
- `loudness_dba` 不再固定为 65
- `input_sources.acoustic_provider` 会变为 `local`

## 已知边界

1. 响度是估算值，不等同于专业校准声级计读数。
2. 停顿检测依赖能量阈值，背景噪声较大时需要调低或调高 `ACOUSTIC_VOICE_THRESHOLD_DBFS`。
3. 发音可懂度仍主要依赖 ASR 是否能输出有效文本，尚未接入专业构音/音素级分析。
